Here's your beginner-friendly, step-by-step guide to moving your Paddle subscription from sandbox to live.

📋 What You're Doing (In Simple Terms)
Right now, your app uses Paddle's sandbox (test mode). No real money changes hands. You want to switch to live mode so customers can actually pay you real money.

Think of it like moving from a practice kitchen to a real restaurant. You need to:

Set up your real menu (products & prices) in Paddle
Get your real API keys (like a secret password between your app and Paddle)
Tell your app where to send real webhooks (Paddle telling your app "someone paid!")
Deploy your app to the live internet
Step 1: Log Into Your Paddle Dashboard
Go to paddle.com and log in to your account
Look for a toggle or dropdown near the top that says "Sandbox" — switch it to Live (or make sure you're in the live environment)
You should now be in your live Paddle account
⚠️ If Paddle asks you to complete business verification first, do that before continuing. They need to verify your business before you can accept real payments.

Step 2: Create Your Products and Prices
In the Paddle dashboard, go to Products (or Catalog):

Click Add Product or Create Product
Create a product called something like "K9 Management System"
Add two prices:
Monthly: $41.00 USD
Yearly: $443.00 USD
Save each price. Paddle will show you an ID for each price — it looks like pri_abc123...
Copy these somewhere safe:

Monthly Price ID: pri_...
Yearly Price ID: pri_...
Step 3: Create Your API Keys
Still in the Paddle dashboard, go to Developer Tools → API Keys (or Authentication):

Click Create API Key
Give it a name like "K9 Management Live"
Select permissions — you'll need:
Read/Write transactions
Read subscriptions
Read catalog (products/prices)
Create portal sessions (for customer billing management)
Copy the API Key — it starts with pdl_live_
Copy the Client Token — it starts with live_
Save these somewhere safe. You won't see them again.

Step 4: Create a Webhook
Still in the Paddle dashboard, go to Developer Tools → Webhooks (or Notifications):

Click Add Webhook or Create Destination
For the URL, enter: https://your-domain.com/api/billing/webhook
Replace your-domain.com with your actual deployed domain
Select the events you want to receive. At minimum:
subscription.created
subscription.updated
subscription.canceled
transaction.completed
transaction.payment_failed
Paddle will show you a Webhook Secret — copy this too!
Save the webhook secret somewhere safe.

Step 5: Update Your Cloudflare Pages Settings
Now you need to tell your app about these live values. Go to your Cloudflare dashboard:

Open your project in Cloudflare Pages
Go to Settings → Environment variables (or Functions settings)
Add or update these variables:
Variable Name	Value	Example
PADDLE_ENVIRONMENT	production	production
PADDLE_API_KEY	Your live key	pdl_live_abc123...
PADDLE_CLIENT_TOKEN	Your live token	live_def456...
PADDLE_MONTHLY_PRICE_ID	Monthly price ID	pri_abc123...
PADDLE_YEARLY_PRICE_ID	Yearly price ID	pri_def456...
PADDLE_WEBHOOK_SECRET	Webhook secret	pdl_ntfset_xyz...
PADDLE_CHECKOUT_ENABLED	true	true
BILLING_V2_ENABLED	false	false
🔒 Never share these values with anyone. They are like passwords.

Step 6: Deploy Your App
Now deploy your code to Cloudflare Pages so the live settings take effect:

Make sure your code changes are saved (the changes I made earlier removed the production block)
Push your code to GitHub, OR deploy directly from Cloudflare Pages
Wait for the deployment to finish
Visit your live website to confirm it's working
Step 7: Test with a Real Payment
Open your live website
Log in as the workspace owner
Go to your subscription/billing page
Click "Subscribe" or "Continue to secure checkout"
Complete the checkout using a real payment method
⚠️ This will charge real money. You can cancel immediately after testing if you don't want to keep the subscription.

Step 8: Confirm Everything Works
Check your Paddle dashboard — you should see the transaction and subscription
Check your app — the subscription status should show as active
Check the billing portal link — you should be able to manage the subscription

Sandbox ≠ Live: Test transactions in sandbox don't carry over. You start fresh in live mode.
